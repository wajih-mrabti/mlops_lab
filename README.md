# ModelOps Lab

A team-oriented MLOps platform for managing the machine learning lifecycle.

## Vision

ModelOps Lab aims to provide a unified platform for:
- Model versioning and registry
- Experiment tracking and training
- Model deployment and rollback
- Performance monitoring and data drift detection
- Team collaboration and access control

## Architecture

The platform will use a Next.js and TypeScript frontend, backed by independent services and APIs introduced incrementally.

The example ML model is maintained separately in the model_client project.
